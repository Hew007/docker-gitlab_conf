# docker-gitlab_conf

[简体中文](README.md) | **English**

A Docker Compose configuration for docker-gitlab and docker-gitlab-runner.

Follow the comments in [docker-compose.yml](docker-compose.yml) to set your IP address, account details, and passwords. Start the services with `docker-compose up -d`.

> If the services start but you cannot reach them, check the server firewall and whether your cloud provider allows traffic on the relevant ports.

For more configuration options, see [docker-gitlab](https://github.com/sameersbn/docker-gitlab).
